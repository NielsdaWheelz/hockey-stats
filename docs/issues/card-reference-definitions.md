# card reference definitions

status: open reference limitation for later components; does not block the current capture or 5v5 design.

problem: public layouts are more complete than current public definitions. a visible label does not supply an estimand, denominator, eligibility rule or reproducible model.

evidence, checked 2026-09-29:

- hockeyviz's [2026–27 preview](https://hockeyviz.com/txt/preview2627) announces rewritten shot-rate and xg models with descriptions forthcoming; older articles cannot establish the new implementation.
- the [current goalie preview](https://hockeystats.com/cards/goalie-cards) displays danger tiers, start-quality categories, rebound control and consistency. the detailed [explainer found](https://jfresh.substack.com/p/2022-nhl-player-cards-explainer) dates to 2022; unchanged current definitions were not established.

impact: the [inventory](../product-inventory.md) can identify these capabilities, but cannot promise current numerical parity or treat historical thresholds as approved requirements.

resolution: when selecting an affected capability, pin a dated reference and define our quantity, population, denominator, time meaning and acceptance evidence. obtain adequate current documentation or explicitly adopt and validate an independent definition. private documentation is not a prerequisite for our own model. delete this record once selected affected quantities have those contracts and remaining reference-only fields are clearly declined or deferred.
