# same-second shift-start chronology

the released execution recipe shares the corrected shift-start eligibility calculation with the spatial event design. a faceoff anchor must precede the shot in saved order. an on-the-fly start must precede the shot on the recorded clock. unavailable start type/zone leaves supported membership and saved shift age intact. the remaining limitation is the physical order within a recorded second. [shared policy](../../analysis/src/hockey_stats/analysis_context.py) · [five-year replacement and scoring](../research/spatial-v1-08/receipts/real-final-score-completion.json)

the original encoder consumed start evidence without those checks. the first real 5v5 spatial preflight refused 54 targets in 54 games in 2021–22, including 50 same-clock on-the-fly starts and four faceoff starts without an earlier anchor. the original fixtures include `2021020002:196` (age zero at 1,066 seconds) and `2021020637:210` (anchor order 212 at 1,049 seconds). the original fits and receipts preserve that failure. [representatives](../research/spatial-v1-08/real-shift-start-representatives.json) · [fixture bindings](../../fixtures/source-admission-v1-08.json) · [repair scope](../research/spatial-v1-08/execution-start-repair-scope.md)

under the corrected rule the first three seasons had zero admitted same-clock faceoffs. the last two had eleven and thirteen respectively, across 306,101 contexts. the independent report found a flip in recorded order and greater pair frequency. saved order does not establish which physical event came first. neither a change in sorting policy nor an on-ice explanation has been established. [independent saved-report comparison](../research/spatial-v1-08/reviews/independent-review.md#real-20252026-source-report)

resolving physical chronology requires independent subsecond ordering evidence. a separately specified comparison that withholds ambiguous same-second starts could instead measure the consequences of this assumption. it could not recover the physical order.
