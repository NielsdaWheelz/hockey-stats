## first tracking study

if tracking work is selected, start with **who made the primary pass leading to an attempt?** a verified passer–attempt link supports primary shot assists per 60 tracked minutes. where the recipient's attempt also has a neutral reference xg value, the link supports our reference expected assists on matched coverage. the current setter model reserves 80% of every eligible attempt's pre-outcome weight for setup. summing those weights would largely measure the allocation rule. recorded first assists constrain fitting on goals and cannot validate passer identity on misses or saves. [tracking field definitions](../specs/experimental-card-facts.md#microstat-quantities-and-populations) · [setter inference](../specs/experimental-chance.md#setter-inference)

1. **source and facts.** establish permitted access to identified games and independent tracking or taggable footage. sample complete regular-season 5v5 shifts with both goalies, independently of outcomes. link each eligible attempt to the primary passer, confirmed no pass, or unknown. include blocks, misses, saves, goals and covered minutes without attempts. retain game, player, event and clock identities. report unobservable attempts and minutes separately.
2. **execution and assessment.** before inspecting held-out labels, fix the sample budget, attribution rule, simple position-and-deployment baseline and criterion for useful improvement. hold out entire games from fitting and tuning. on attempts with decidable credit, compare how often each method identifies the passer or correctly assigns no pass. report non-goals separately. compare absolute error in each player's shot assists per 60 over the same covered minutes. use only information available before the outcome when assigning the passer.
3. **decision.** report coverage and whether the candidate improves on the baseline at both levels. a useful result can justify a separately named *estimated* shot-assist rate. only admitted tracked links can populate the observed pass fields, and only for their covered population. inconclusive evidence leaves the source gap open. the existing modeled context can ship independently.
