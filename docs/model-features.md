## attribution exposure context

04n uses home/period/clipped-score context over matched elapsed exposure. [completed 04o](research/attribution-04o/decision.md) implements and retains eighteen fixed within-period time/score columns without adopting them. new temporal shape uses the existing forty modes; old coarse context retains its native maps. no selected smoothing penalty is added. pre-event score and clock facts supply exact event terms and integrated zero-event exposure, centered using training time only. a midpoint or attempt-level `game_detail` value is not this contract. player shape, corrected population and annual borrowing remain unchanged. regional prediction gain is unresolved, native inverse-share loss is higher, and player consequences are point sensitivities, not validated recovery or uncertainty. correct extraction remains available independently of the evidence against selecting it.

`shift_age`/`shift_start` availability likewise does not provide elapsed-time attribution: skaters have distinct histories, and `no_same_clock_faceoff` does not prove an on-the-fly start. preserve these capabilities without silently selecting them or controlling away player-created mechanisms.
