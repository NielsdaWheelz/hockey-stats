## tradeoffs

- overview moves large evidence reads to explicit interactions and exports. full named family responses still carry the corresponding evidence, so a table download can make more requests than initial discovery.
- the comparative png has bounded interpretation and histories. detailed inspection belongs to the page and csv.
- replacement of even an unrelated compiled backend file, node runtime or lockfile invalidates the receipt. startup still hashes the database, and explicit admission reads it before and after the semantic checks.
- staging and same-schema restore need an extra database copy. cross-schema rollback uses the compatible historical runtime and its original full startup.
- territory correction binds the original raw strings and diagnostic sources. it writes one metadata-only successor, then the normal publisher builds the database. retained evidence and numerical values keep their original meanings.
