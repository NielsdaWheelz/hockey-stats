## comparisons, uncertainty and interpretation

pair complete recognized streams on `(game_id, source_index)` with identical event ids, dates/seasons, labels, status/applicability and source identities. missing, duplicate or mismatched keys fail; no silent intersection. within each quantity/window compare changed recipes with baseline. primary metric is pooled mean goal log loss in nats per applicable attempt, `delta=changed−baseline`; never combine the two quantities. also retain brier, predicted-minus-observed rate in percentage points, twenty own fixed bins, named groups and actual resource measurements.

context/type/month group memberships come from common frozen source descriptors. paired actor-support group comparisons use BASELINE-defined memberships; each changed component's own support ledger is reported separately. prediction-selected bins are own calibration summaries, not different cohorts to subtract as paired loss populations.

reuse native whole-game and 7/14-calendar-day paired bootstrap arithmetic: 2,000 draws, `PCG64`, seed `3032026`, 95% linear percentiles, pooled additive sums/counts. calendar blocks start at the earliest selected date; retain empty games/days, intervening empty blocks and the final partial block. any undefined draw makes the interval null, without redraws. show contributing games/blocks. intervals are pointwise and condition on fitted models; they omit fitting, selection and physical-origin uncertainty. calendar horizons are sensitivity checks, not a dependence proof. no fits are repeated for resampling.

03e's overall goal ±0.0025, subgroup goal ±0.01, overall marginal-unblocked ±0.01 and subgroup marginal-unblocked ±0.03 margins are historical reference lines only. no screen admission threshold is selected from results.

the written decision labels each changed-recipe/quantity pair: either window unavailable/nonconverged → `incomplete`; both point deltas negative → `consistent_direction`; neither negative → `no_improvement`; exactly one negative → `mixed_direction`. zero is not improvement. these labels describe point estimates, not demonstrated superiority. interval overlap with zero does not prove equivalence or prohibit a bounded follow-up. if both recipes improve, report them separately; their combination is untested. report adverse brier/calibration tradeoffs. no negative direction means `no_revision_identified`, a complete screen outcome.
