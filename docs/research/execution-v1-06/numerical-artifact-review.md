## blockers

1. `_resolve` omits required diagnostics. `_event_probe_changes` returns only a maximum, so the receipt contains no expected-sum movement on frozen actual keys, no exact populations for those sums, and no count of neutral danger-threshold crossings. retain the baseline danger bins for paired comparisons and report crossings separately. synthetic geometry/witnesses must not enter an actual-key expected total.

2. full-panel neutral propagation covers only public panels with selected focal pairs. `_resolve` builds seven public panels and skips a strength when no player is selected. neutral total movements must cover all32 exact physical panels independently of the at-most45 focal-pair union. evaluate neutral panels without expanding focal selection; record each physical population/count and baseline/variant total.

3. the detached reader checks panel shapes, membership and global scalar/map sums but does not bind saved logits to event neutral prefixes or projection neutral masses. a coherent shape can therefore carry different saved numerical evidence. use the shared numerical helpers below after the existing strict array checks; do not recreate probability products in the artifact module.

4. the detached reader accepts incoherent standardized stage values. `_projections` range-checks the four stages but checks panel-mass closure only for finishing/setting. it never verifies stage differences against the common neutral stages, available focal ratios where representable, or stage nullability against the required focal coefficient chain and nonempty panel. the actual reader accepted on-net probability `0.36153237618937867` after replacing saved `0.7230647523787573`, with its difference/masses/maps unchanged. the temporary `numerical_artifact_check.py` exercises this actual reader boundary by replacing one decoded projection row after normal file/hash checks, without changing a file.

5. final-year resolution validation is too weak for a claimed completed receipt. it checks head order and four maxima but not the closed selector/requirement structure, equality of top-level and selector pairs, pair uniqueness/identity, comparison coverage of every frozen pair, or the frozen event/synthetic population structure. the existing reader would accept a removed/repeated pair list while retaining unrelated passed comparisons. bind these saved internal relationships; provenance paths remain locators and must not be reopened.

## narrower issues

- `_event` skips conditional-prefix closure whenever the denominator is below `1e-250`, including many ordinary representable divisions. a direct event-boundary check accepted saved `.9` where numerator `1e-254` divided by denominator `1e-252` is `.01`. that is an arbitrary numerical cutoff, not the underflow boundary. check ratios wherever division retains sufficient floating-point resolution; preserve genuinely representable saved conditionals when stored joint mass underflows. no epsilon or invented no-exposure value.
- `_event_probe_changes` includes retrospective setter-posterior movement in the `1e-5` probability gate. that is an additional acceptance gate beyond the specified integrated prefixes/terminals/coalitions/shares, and it can be sensitive near negligible branch likelihood. record posterior sensitivity separately unless the specification explicitly selects it. pre-outcome prior weights remain invariant.
- the writer retains all per-player projections and maps before serialization. this avoids an all-player×origin tensor but still retains all native maps; record the measured memory cost and keep the annual/source panel duplication visible in extrapolation.
