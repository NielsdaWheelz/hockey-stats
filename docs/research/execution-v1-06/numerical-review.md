## mathematical contracts

- integrate joint prefixes under the same origin/setter prior. the equal-weight hand case `u=q=(.9,.1), r=g=1` gives goal mass `.41`, second-stage probability `.82`, goal given unblocked `.82`, and goal given on-net `1`.
- compute finite-logit conditionals from integrated log prefixes. the checked extreme case has stored unconditional mass zero by floating-point underflow but representable conditional goal probability `.125`. fixed event conditional fields preserve this distinction detached; no epsilon or probability clipping is used.
- standardize every focal skater on the same exact-state panel. setting uses setup mass, not physical count: setup weight `.8` and conditional contrast `.1` produce `10` goals per100 setup opportunities. the tip-only shooter contrast is zero.
- enumerate all sixteen coalitions. the four-group subset formula agrees with an independent enumeration of all twenty-four actor permutations. preserve candidate prior weights when assigning setter credit; none, unknown and known goalie setters receive zero setter deviation.
- reuse saved prefix goal masses for coalition entries `0`, `11`, `15`. those fields identify the same quantities. branchwise allocation remains independently computed and closes within bounded floating-point arithmetic.
- deposit globally normalized differences into native cells. map sums equal finishing/setting scalars. no cell receives a separate denominator.

## responsible owners and review repairs

`execution.py` owns one logits/coalition engine for the public branch evaluator, reference calls and annual/probe event scoring. panel probability products use the same log-prefix primitive. probes change coefficients and centers while preserving baseline membership, origin weights, setup weights and actor/label support.

`ExecutionDesign.scoring_facts` preserves known source identities, physical state and type even when missing unrelated predictor information excludes an event. `observed_setters` retains the existing likelihood-only labels without rebuilding sparse batches or changing candidate priors. these are transient fields; frozen fit coverage, recipes, objective definitions and state files remain unchanged.

likelihood support is a union of distinct physical source keys, not the structural support counter. setter candidate and mean-coupled sets may overlap. carried historical prior years remain visible even when a focal term also has current information. a missing coefficient propagates only to dependent prefixes/stages; an empty panel remains distinct. exact-strength participation qualifies the viewing cohort and is supplied by the factual membership owner.
