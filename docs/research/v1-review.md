## findings that change what we build

1. **test the estimates currently on the cards.** execution combines conditional outcomes into a valid all-attempt distribution. the inspected scoring path uses a pre-outcome setter mixture. the review found no demonstrated headline sign, probability or ledger error in the paths examined. a recorded block determines when origin reconstruction is used, so the resulting retrospective opportunity score uses information a pre-shot forecast would lack. positive lineup volume, spatial shares and reference quality produce nonnegative physical rates. the older 04n model reduced held-out complete regional loss by 0.108809 (recorded unblocked attempts/60)² against independent fitting, with unresolved native-cell improvement. earlier known-truth studies struggled to separate player effects. the current recipes still lack a matched held-out comparison against simple alternatives. lineup prediction, individual recovery and optimizer sensitivity each answer different questions. [scoring](../../analysis/src/hockey_stats/execution.py) · [04n](attribution-04n/decision.md) · [04e](attribution-04e/decision.md) · [public xg assessment](https://hockeystats.com/methodology/expected-goals) · [active and retained inputs](../model-features.md#experimental-use)
2. **explain where the index has leverage.** in a read of all 940 skaters in the 2025–26 publication, the 5v5 offense term reaches about −27 goals for a skater with seven reported all-strength minutes. these minutes differ from effective fitting support. both territorial terms are individually below 0.1 goal in absolute value for every skater in that roster. trace current evidence, history, shared deployment and successive unit conversions before changing a prior. a separate diagnostic allocation reaches 513 million against attempts per 60 while the corresponding factual prediction is about 192. the opposing terms cancel. inspect the counterfactual lineups before interpreting individual credits. the depth forward and defense groups both sit below their position's usage-weighted mean, although their offsets from the virtual league reference differ in sign. identify the depth group when reporting replacement value. [low-minute cases](../issues/low-exposure-player-effects.md) · [territorial scale](../issues/territory-value-scale.md) · [ledger construction](../../analysis/src/hockey_stats/player_value.py) · [extreme allocations](../issues/spatial-actual-context-extremes.md) · [territory diagnostics](territory-v1-11/verification.md)
3. **make the reader's question visible.** the saved images show five distinct compositions. dense methods text competes with maps and component estimates, and six significant digits can imply unwarranted precision. use quantity-specific rounding at display time. keep units, reference, coverage, material prior dependence and numerical caveats legible on the image. retain exact values and full evidence in the page and csv. full-rink coverage is a deliberate choice. [real browser and export evidence](application-v1-20/verification.md#real-read-and-card-acceptance) · [current formatter](../../app/src/web/analysis-history.tsx)
4. **give cohorts a smaller data contract.** the live 2025–26 skater overview returned 34,755,573 bytes for 940 people. the recorded three-season profile and comparison journeys transferred 104.23 and 139.19 mb. population responses carry far more than the values and eligibility needed for distributions, rankings and history. measure complete journeys including opening evidence and exporting. we favor a scalar projection before considering a cache of the large responses. [journey measurements](../issues/profile-history-payload-cost.md) · [client](../../app/src/web/client.ts)
5. **bind a snapshot to the bytes actually consumed.** original captures, empty responses, chronology and matched event/time exclusion are well represented. 6,560 games and 2,060,996 original events reconciled. the corpus writer records a derived game file's relative path without pinning its hash. readers could use different versions under one manifest identity. the accepted v1 composition had separate checks. on 2026-11-23 the live player api returned `SeasonNotFound` for `20262027` and listed only the three published seasons. the observed reducer requires a full 1,312-game inventory. a dated schedule, completion evidence and exact game versions are needed to put this season on the cards. [corpus writer](../../analysis/src/hockey_stats/corpus.py) · [observed reader](../../analysis/src/hockey_stats/observed.py#L750) · [source reconciliation](evidence-v1-01/verification.md) · [current-season evidence and acceptance](../issues/current-season-snapshot.md)
6. **examine exclusions before buying more model detail.** one accounting-conflict reason touches 392,921 of 444,786 known resolved excluded seconds. reasons overlap, and 542,339 further known seconds are unresolved. 57 games have empty shifts despite the bounded recovery probe. sample high-impact conflicts from originals and examine recording drift by season. only a localized, evidenced correction justifies enlarging support. [reason coverage](evidence-v1-01/verification.md) · [empty shifts](../issues/empty-shift-source.md) · [shot-type drift](../issues/recorded-shot-type-drift.md)
7. **make another iteration affordable.** five-season preparation took 9.37 hours and wrote 397.8 gb. a three-string territory methods change required a 77-minute exchange successor, a 295-minute build, a 23-minute table comparison and a 59-minute strict admission. the database held 42.7 million rows. retain methodological meaning and numerics in artifacts. render mutable wording from that evidence. profile repeated game reads and per-row checks before optimizing them, then prove the same coverage, values and defect detection. [preparation](evidence-v1-01/verification.md) · [build and admission](application-v1-20/verification.md#drive-backed-candidate-and-preservation)
8. **keep release identity enforceable on the actual mac.** the accepted startup rehashes the file in about 15 seconds. post-rotation metadata changes also caused two refused live starts and one refused preview. the exact writer is unknown. the successful switch previewed the final pathname, then switched listeners. review the identity comparison against the one-operator threat model, preserve rejection of changed bytes and provide an actionable failure reason. retain small regression checks at shared boundaries as their owners change. [metadata issue](../issues/macos-publication-file-identity.md) · [delivery evidence](application-v1-20/verification.md) · [testing policy](../specs/07-lightweight-testing.md)

three specialist reviews covered numerical producers, pipeline and peer/product coverage. an independent opus review challenged the operating and engineering conclusions. it favored caching first and relocating serving files. response size is measured, cache memory cost is unknown, and the metadata writer is unproved. the roadmap therefore starts with a smaller response contract and a focused identity decision. the audit used repository code, named receipts, retained real exports, a live overview read and a bounded read of published ledger rows. browser control was unavailable for a new interactive pass. no fit or source replay was part of this review.
